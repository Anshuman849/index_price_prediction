# 📉 Unemployment Index Prediction

This project focuses on analyzing and predicting the Unemployment Index using Multiple Linear Regression. It involves performing Exploratory Data Analysis (EDA) on a real-world dataset to identify patterns and relationships between economic indicators.

---

## 🚀 Features
- 📊 Exploratory Data Analysis (EDA)
- 📈 Data visualization and insights
- 🤖 Multiple Linear Regression model
- 🔍 Relationship analysis between variables
- 📉 Unemployment trend prediction

---

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook / VS Code

---

## 📂 Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Training (Multiple Linear Regression)
6. Model Evaluation

---

## 📊 Exploratory Data Analysis
- Checked missing values and handled them
- Correlation analysis between variables
- Data visualization using graphs (heatmap, scatter plots)
- Identified key factors affecting unemployment

---

## 🤖 Model Used
- Multiple Linear Regression to predict unemployment index based on multiple independent variables

---

## 📈 Results
- Model performance evaluated using metrics like:
  - R² Score
  - Mean Squared Error (MSE)
- Showed strong relationship between selected features and unemployment index
